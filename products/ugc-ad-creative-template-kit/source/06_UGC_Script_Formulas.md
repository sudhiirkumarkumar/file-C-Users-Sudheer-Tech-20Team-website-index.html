# 06 — 25 UGC Script Formulas (Bonus 3)
## Reusable Story Structures — With Exactly When to Use Each One

---

## How to Use a Formula

1. Choose the formula that matches your **audience awareness** and **objective** (selector table at the end).
2. Write **one sentence per block**. Most 15–30 second ads need only 5–7 sentences.
3. Assign each block a **visual** — if you can't picture it, simplify it.
4. Read it aloud with a timer. Cut words until it fits.

**Awareness levels used below:**
- **Unaware** — doesn't know they have the problem
- **Problem-aware** — feels the pain, doesn't know solutions
- **Solution-aware** — knows solutions exist, comparing options
- **Product-aware** — knows you, hasn't bought
- **Customer** — has bought, could buy again or refer

---

### F01 · The Classic UGC Arc
**HOOK → PROBLEM → DISCOVERY → DEMO → RESULT → CTA**
- **Use when:** you have a clear problem and a demonstrable product. Default for most first ads.
- **Awareness:** Problem-aware
- **Length:** 20–30s
- **Example:** "I wish I found this sooner (hook). My cables were always falling behind my desk (problem). Then I found Hookline clips (discovery). Stick, clip, done (demo). Haven't crawled under my desk since (result). Linked below (CTA)."

### F02 · The POV Relatable
**POV → PROBLEM → PRODUCT → REACTION → RECOMMENDATION**
- **Use when:** targeting cold audiences on TikTok/Reels where native, low-VO content performs; works with trending audio.
- **Awareness:** Unaware → Problem-aware
- **Length:** 8–15s

### F03 · The Transformation
**BEFORE → DISCOVERY → AFTER → PROOF → CTA**
- **Use when:** the result is visual (cleaning, skincare, organising, fitness, design).
- **Awareness:** Problem-aware
- **Length:** 15–25s

### F04 · The Honest Review
**CLAIM → PROS → CON → VERDICT → CTA**
- **Use when:** retargeting people who've seen your product but hesitate; the balance builds trust.
- **Awareness:** Product-aware
- **Length:** 25–40s

### F05 · The Sceptic Flip
**DOUBT → OBJECTION → TEST → SURPRISE → PROOF → CTA**
- **Use when:** your category has a trust problem ("another subscription?", "too good to be true").
- **Awareness:** Solution-aware / Product-aware
- **Length:** 20–30s

### F06 · The List Value
**PROMISE ("3 things…") → ITEM 1 → ITEM 2 → ITEM 3 (PRODUCT) → CTA**
- **Use when:** you want saves/shares and a soft sell. Product is always the final list item.
- **Awareness:** Unaware → Problem-aware
- **Length:** 20–30s

### F07 · The Mistake Correction
**MISTAKE → CONSEQUENCE → CORRECT WAY → PRODUCT → CTA**
- **Use when:** your audience does something common that your product improves.
- **Awareness:** Unaware
- **Length:** 15–25s

### F08 · The Founder Origin
**PERSONAL PROBLEM → FAILED SEARCH → BUILD → RESULT → INVITATION**
- **Use when:** brand-building, launches, differentiation against bigger competitors.
- **Awareness:** Any
- **Length:** 30–45s

### F09 · The Unboxing Reveal
**ANTICIPATION → OPEN → DETAILS → FIRST USE → REACTION → CTA**
- **Use when:** packaging or product experience is a selling point; gifting season.
- **Awareness:** Solution-aware
- **Length:** 20–30s

### F10 · The Demo First
**RESULT → STEP 1 → STEP 2 → STEP 3 → RESULT AGAIN → CTA**
- **Use when:** "how easy is it?" is the main objection. Showing the result first earns the watch.
- **Awareness:** Solution-aware
- **Length:** 15–25s

### F11 · The Us vs The Usual Way
**USUAL WAY → ITS FLAW → OUR WAY → WHY IT'S BETTER → CTA**
- **Use when:** buyers compare categories (never name competitors; compare approaches).
- **Awareness:** Solution-aware
- **Length:** 15–25s

### F12 · The Timeline Diary
**START → DAY X → DAY Y → DAY Z → VERDICT → CTA**
- **Use when:** results build over time (habits, skincare, apps, fitness).
- **Awareness:** Problem-aware / Product-aware
- **Length:** 25–40s

### F13 · The Comment Reply
**QUESTION (REAL COMMENT) → ACKNOWLEDGE → ANSWER → PROOF → CTA**
- **Use when:** repeated questions/objections show up in comments or DMs.
- **Awareness:** Product-aware
- **Length:** 15–30s

### F14 · The Routine Insert
**ROUTINE INTRO → STEP → PRODUCT STEP ★ → STEP → CTA**
- **Use when:** product fits into a daily routine and you want a natural, non-salesy placement.
- **Awareness:** Unaware → Solution-aware
- **Length:** 20–35s

### F15 · The Replace-Many
**CLUTTER → ITEMS REMOVED → ONE PRODUCT → ALL JOBS SHOWN → CTA**
- **Use when:** multi-use products; value justification for higher prices.
- **Awareness:** Solution-aware
- **Length:** 15–25s

### F16 · The Third-Party Notice
**SOMEONE NOTICED → THEIR REACTION → REVEAL → CONTEXT → CTA**
- **Use when:** the result is noticeable by others (appearance, home, cooking, confidence).
- **Awareness:** Unaware
- **Length:** 15–25s

### F17 · The Myth Buster
**MYTH → TRUTH → REASON → BETTER APPROACH (PRODUCT) → CTA**
- **Use when:** misconceptions block purchase ("natural products don't work", "AI notes are inaccurate").
- **Awareness:** Solution-aware
- **Length:** 20–30s

### F18 · The Social Proof Stack
**PROOF 1 → PROOF 2 → PROOF 3 → PRODUCT → CTA**
- **Use when:** you have lots of genuine reviews or customer clips; retargeting.
- **Awareness:** Product-aware
- **Length:** 20–30s

### F19 · The Offer Reminder
**HEADS-UP → OFFER → WHY IT'S WORTH IT → REAL DEADLINE → CTA**
- **Use when:** running a genuine promotion to a warm audience.
- **Awareness:** Product-aware / Customer
- **Length:** 10–20s

### F20 · The Starter Guide
**"IF I STARTED TODAY" → ESSENTIAL 1 → ESSENTIAL 2 (PRODUCT) → SKIP THIS → CTA**
- **Use when:** beginner audiences feel overwhelmed; starter kits and bundles.
- **Awareness:** Problem-aware
- **Length:** 20–30s

### F21 · The Breaking Point Story
**THE BAD MOMENT → EMOTION → SEARCH → PRODUCT → CALM REPLAY → CTA**
- **Use when:** the pain is emotional and relatable; storytelling-friendly creators.
- **Awareness:** Problem-aware
- **Length:** 25–35s

### F22 · The Behind the Scenes
**INVITE ("come with me") → PROCESS → CARE DETAIL → FINISHED PRODUCT → CTA**
- **Use when:** handmade, small-batch or quality-driven brands; builds affinity.
- **Awareness:** Unaware → Solution-aware
- **Length:** 15–30s

### F23 · The Challenge / Stress Test
**CLAIM → TEST SETUP → TEST → RESULT → VERDICT → CTA**
- **Use when:** durability, performance or longevity is the main claim.
- **Awareness:** Solution-aware
- **Length:** 15–25s

### F24 · The Question Hook Q&A
**QUESTION → "HERE'S THE ANSWER" → EXPLANATION → PRODUCT AS TOOL → CTA**
- **Use when:** educational niches (finance, fitness, software, cooking) where people search questions.
- **Awareness:** Problem-aware
- **Length:** 20–35s

### F25 · The Long-Term Update
**THEN (OLD CLIP) → NOW → STILL USING? → WHY IT STUCK → TIP → CTA**
- **Use when:** you need proof of lasting value; subscriptions, durable goods, habits.
- **Awareness:** Product-aware
- **Length:** 20–30s

## Formula Selector

| If your goal is… | …and your audience is… | Use |
|---|---|---|
| First ad for a new product | Cold | F01, F02, F06 |
| Visual result | Problem-aware | F03, F10, F23 |
| Overcome doubt | Product-aware | F04, F05, F13, F17 |
| Brand trust | Any | F08, F22 |
| Saves & shares | Cold | F06, F07, F24 |
| Daily-use product | Cold | F14, F16 |
| Price justification | Solution-aware | F11, F15 |
| Retargeting | Warm | F04, F18, F25 |
| Promotion | Warm | F19 |
| Beginners | Problem-aware | F20, F24 |
