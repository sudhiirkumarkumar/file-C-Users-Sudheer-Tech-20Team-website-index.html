# 09 — AI UGC Script Prompt Pack (Bonus 6)
## 24 Copy-and-Paste Prompts for ChatGPT, Claude or Any AI Assistant

---

## Before You Start: Your Brand Brief

Paste this brief at the top of any conversation (or save it as a custom instruction / project instruction). Every prompt below gets better when the AI knows these details.

```
BRAND BRIEF
Product name: [ ]
What it is (one sentence): [ ]
Price: [ ]
Who buys it (age, lifestyle, situation): [ ]
Top 3 problems it solves: [ ]
Top 3 benefits (in customer words): [ ]
Proof I can honestly use (reviews, stats, tests): [ ]
Biggest objections: [ ]
Brand voice (3 adjectives): [ ]
Words/claims to avoid: [ ]
Platforms: [ ]
```

**Rules to add to every prompt (already included below):** no guaranteed results, no invented reviews or statistics, conversational spoken English, short sentences.

## A. Script Generation (8)

### Prompt 01 — Five Scripts From One Formula
```
Using my brand brief, write 5 different UGC video scripts for [PRODUCT] using this formula: HOOK → PROBLEM → DISCOVERY → DEMO → RESULT → CTA.
Each script: 20–25 seconds when spoken, one sentence per block, written how a real person talks to their phone camera.
For each script include a table with columns: Time | Visual | On-screen text (max 8 words) | Voiceover.
Use a different hook angle for each (curiosity, problem, confession, POV, story).
Do not invent statistics, reviews or guaranteed results.
```

### Prompt 02 — Fill a Kit Template
```
Here is a UGC ad template from my kit:
[PASTE TEMPLATE CARD]
Rewrite it completely for my product using my brand brief. Keep the timing and structure. Replace every [bracket]. Give me: hook, full timeline table, B-roll list, caption and CTA.
```

### Prompt 03 — Honest Review Script
```
Write a 30-second honest review script for [PRODUCT] in the format: CLAIM → 2 PROS → 1 MINOR CON → VERDICT → CTA.
The con must be realistic and minor (e.g., [price/colour options/size]). Tone: calm, balanced, not hyped. Include on-screen text for each section.
```

### Prompt 04 — Founder Story
```
Interview me to write a founder-story UGC ad. Ask me 6 questions one at a time about why I started [BRAND], the problem, early versions, and what customers say.
After my answers, write a 30–40 second founder script (formula: PERSONAL PROBLEM → FAILED SEARCH → BUILD → RESULT → INVITATION) using only the facts I gave you.
```

### Prompt 05 — Screen-Record Demo (SaaS/Digital)
```
Write a 25-second screen-recording UGC script for [APP/DIGITAL PRODUCT]. The creator appears in a face bubble.
Show: the task, the 1–2 features that make it fast, the finished result.
Output a timeline with: Time | What's on screen | Cursor/zoom instruction | On-screen text | Voiceover.
```

### Prompt 06 — Sceptic Flip
```
My customers' biggest objection is: "[OBJECTION]".
Write 3 UGC scripts (20–30s) using the formula DOUBT → OBJECTION → TEST → SURPRISE → PROOF → CTA. Each should voice the objection in a different, natural way. Use only the proof in my brand brief.
```

### Prompt 07 — Educational Value-First Script
```
Write a "3 mistakes" educational UGC script for people interested in [TOPIC]. Mistakes 1 and 2 must be genuinely useful free advice that does NOT mention my product. Mistake 3 should naturally lead to [PRODUCT] as the solution. 25–30 seconds, include on-screen text.
```

### Prompt 08 — Offer Script (Honest)
```
Write 3 short UGC scripts (12–18s) promoting this real offer: [OFFER DETAILS, END DATE/TIME].
Tone: friendly reminder, not pushy. No fake scarcity, no "last chance ever", no invented stock levels. State the real end date clearly.
```

## B. Hooks & Angles (5)

### Prompt 09 — 30 Hooks by Angle
```
Write 30 UGC video hooks for [PRODUCT] — 3 each for these angles: curiosity, problem, story, confession, review, product discovery, educational, comparison, POV, social proof.
Each hook: under 15 words, sounds like natural speech, specific to my customer's real situation. No clickbait claims.
```

### Prompt 10 — Hooks From Real Reviews
```
Here are real customer reviews:
[PASTE REVIEWS]
Pull out the most vivid phrases customers use, then write 15 UGC hooks that use their exact language. Label which review each hook came from.
```

### Prompt 11 — Angle Finder
```
Based on my brand brief, list 10 distinct advertising angles for UGC ads (e.g., time saved, identity, gifting, replacing multiple products, avoiding a common mistake).
For each angle give: who it's for, the core emotion, one hook, and which template type suits it (problem/solution, discovery, testimonial, demo, founder, educational, offer).
```

### Prompt 12 — Visual Hook Ideas
```
For [PRODUCT], suggest 15 first-frame visuals (0–2 seconds) that would stop someone scrolling, without needing text or sound. Must be filmable on a phone at home. Describe each in one sentence.
```

### Prompt 13 — Hook Variations for Testing
```
Here is a winning UGC ad script:
[PASTE SCRIPT]
Keep everything after the first 3 seconds identical. Write 10 alternative openings (hook line + on-screen text + first visual) so I can A/B test them.
```

## C. Captions, CTAs & Copy (4)

### Prompt 14 — Captions
```
Write 5 captions for this UGC video: [PASTE SCRIPT].
Mix lengths: 2 short (1 line), 2 medium (3 lines), 1 story-style (5–6 lines). Each ends with a clear CTA and one engagement question. Max 3 relevant hashtags. No hype words like "revolutionary" or "game-changer".
```

### Prompt 15 — Paid Ad Copy Set
```
Turn this UGC video script into paid social ad copy: [PASTE SCRIPT].
Give me: 5 primary text options (under 125 characters each), 5 headlines (under 40 characters), and 3 descriptions (under 30 characters). Keep claims honest and consistent with the video.
```

### Prompt 16 — CTA Matcher
```
My ad objective is [SALES/TRIAL/LEADS/TRAFFIC] and my audience is [COLD/WARM]. Suggest 10 spoken CTAs and matching on-screen CTA text for [PRODUCT], ranked from lowest to highest commitment.
```

### Prompt 17 — Photo Ad Copy
```
Write copy for 5 static UGC photo ads for [PRODUCT] using these layouts: selfie testimonial, product-in-hand, before/after, comparison table, FAQ card.
For each: headline (max 8 words), supporting text (max 20 words), CTA, and one-sentence photo direction.
```

## D. Planning, Adaptation & Review (7)

### Prompt 18 — Industry Adapter
```
Here is a UGC template written for a different industry:
[PASTE TEMPLATE]
Adapt it for [MY INDUSTRY] and [PRODUCT]. Change the problem, visuals, B-roll and example so it feels native to my audience. Keep the structure and timing.
```

### Prompt 19 — Shot List From Script
```
Create a shot list for this UGC script: [PASTE SCRIPT].
Table columns: Shot # | Description | Framing (close/medium/wide) | Angle | Duration to record | Props needed. Add 5 extra B-roll shots I could reuse in other ads.
```

### Prompt 20 — 30-Day Content Plan
```
Using my brand brief, create a 30-day UGC content calendar.
Week 1 attention, week 2 problem & proof, week 3 trust, week 4 conversion. 60% video, 40% photo/carousel/story. For each day: format, template type, hook, one-line topic and CTA. Output as a table.
```

### Prompt 21 — Creator Brief
```
Write a one-page brief I can send to a UGC creator for [PRODUCT].
Include: product summary, key messages (max 3), must-show shots, do's and don'ts, claims they cannot make, deliverables (number of videos, length, ratio, raw files), and 3 example hooks.
```

### Prompt 22 — Script Critic
```
Act as a strict UGC ad editor. Review this script: [PASTE SCRIPT].
Score it 1–10 on: hook strength, clarity, authenticity (sounds natural?), visual potential, CTA clarity, and compliance (any unsupported claims?). Then rewrite it fixing the weakest two areas.
```

### Prompt 23 — Compliance Check
```
Review this ad script and caption for claims that could be misleading or break advertising platform policies: [PASTE].
Flag: unsupported results, health/income claims, fake urgency, implied endorsements, before/after issues. Suggest compliant rewrites for each flagged line.
Note: I will still check the platform's current ad policies myself.
```

### Prompt 24 — Repurpose One Video Into Ten
```
Here is my best-performing UGC ad script: [PASTE].
Repurpose it into: 3 new video variations (different hooks/formulas), 3 static photo ads, 1 carousel (5 slides), 1 story sequence (4 frames), 1 LinkedIn post and 1 Pinterest pin description.
```

---

## Prompting Tips

1. **Give real inputs.** Paste reviews, FAQs and product specs — the AI can't invent proof you don't have (and shouldn't).
2. **Ask for tables.** Timeline tables drop straight into your shooting plan.
3. **Iterate:** "Make it sound more casual", "Shorter — 15 seconds", "Less salesy", "More specific to [customer type]".
4. **Always fact-check** every claim before filming. You are responsible for what your ads say.
