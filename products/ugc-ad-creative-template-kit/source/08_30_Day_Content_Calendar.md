# 08 — 30-Day UGC Content Calendar (Bonus 5)
## A Ready-Made Posting Plan Using the Templates in This Kit

---

## How the Calendar Works

- **4 themed weeks**, each moving the audience one step closer to buying:
  - **Week 1 — Attention:** discovery, POV, educational (cold reach)
  - **Week 2 — Problem & Proof:** problem/solution, demos (build desire)
  - **Week 3 — Trust:** testimonials, founder, reviews (overcome doubt)
  - **Week 4 — Conversion:** offers, comparisons, FAQs (ask for the sale)
- **Days 29–30:** review and plan next month.
- **Mix:** ~60% video, ~40% photo/carousel/story.
- **Batch:** film Week 1 + Week 2 on one day, Week 3 + Week 4 on another, using the Shot List (File 07).
- **Ad-ready:** any post that performs well organically (above-average saves, shares or watch time) becomes a paid-ad candidate — mark it in the "Boost?" column.

**Legend:** Template codes refer to File 02 (V = video) and File 03 (P = photo). Hook numbers refer to File 04. CTA numbers refer to File 05.

|---|---|
