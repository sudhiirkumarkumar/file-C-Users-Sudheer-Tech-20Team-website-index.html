# 03 — UGC Photo Templates
## 24 Static Ad Layouts for Feed, Stories, Carousels & Paid Social

---

## How to Use These Templates

Each photo template card includes: **headline, supporting text, CTA, photo direction, layout structure, recommended ratio and example copy.**

**Standard sizes**

| Ratio | Pixels | Best for |
|---|---|---|
| 4:5 | 1080 × 1350 | Instagram & Facebook Feed (recommended default — takes the most screen space) |
| 1:1 | 1080 × 1080 | Feed, marketplace, carousel |
| 9:16 | 1080 × 1920 | Stories, Reels cover, TikTok photo mode |
| 2:3 | 1000 × 1500 | Pinterest |

**Layout legend** used in the diagrams:
`[IMG]` photo area · `[H]` headline · `[S]` supporting text · `[CTA]` button/pill · `[LOGO]` small logo · `[UI]` native-style element (bubble, comment, star row)

**The 3-second rule:** a static UGC ad must be understood in 3 seconds. Headline ≤ 8 words. Supporting text ≤ 20 words. One CTA.

### P01 · The Selfie Testimonial

| | |
|---|---|
| **Headline** | "I didn't expect to love it this much." |
| **Supporting text** | [Customer first name], [timeframe] using [Product] |
| **CTA** | See why → |
| **Ratio** | 4:5 |

**Photo direction:** Front-camera selfie of the customer (or creator) holding the product near their face. Natural light, genuine smile, everyday background. No heavy retouching.

**Layout structure**
```
┌───────────────────────┐
│ [H] quote, top-left   │
│                       │
│        [IMG]          │
│   selfie + product    │
│                       │
│ [S] name · timeframe  │
│ [CTA pill]    [LOGO]  │
└───────────────────────┘
```
Headline in a white rounded box with 90% opacity. Name in small caps below.

**Example copy — "Solenne Barrier Cream":** Headline: "My skin finally stopped feeling tight." · Supporting: "Priya, 6 weeks with Solenne" · CTA: "See why →"

### P03 · The Product-on-Desk Flat Lay

| | |
|---|---|
| **Headline** | "My [workday/morning] essentials." |
| **Supporting text** | Labels pointing to each item |
| **CTA** | Get the [Product] |
| **Ratio** | 4:5 |

**Photo direction:** Top-down shot of a real desk/counter with 3–5 items; your product in the centre-right "sweet spot". Coffee cup, notebook, phone for context.

**Layout structure**
```
┌───────────────────────┐
│ [H] top-left          │
│   [IMG] overhead      │
│   item ←label         │
│   [PRODUCT] ←★label   │
│   item ←label         │
│ [CTA]          [LOGO] │
└───────────────────────┘
```
Handwritten-style arrow labels pointing to items; your product gets a ★.

**Example copy — "DeskNest Monitor Riser":** "My WFH setup essentials." · Labels: "notebook", "DeskNest ★ fixed my neck", "the good pen" · "Get the DeskNest"

### P04 · The Honest Before / After

| | |
|---|---|
| **Headline** | "Same [spot], [time] apart." |
| **Supporting text** | No filter. Same lighting. Just [Product]. |
| **CTA** | Try it yourself |
| **Ratio** | 4:5 (split vertically) or 1:1 (split horizontally) |

**Photo direction:** Two photos from an identical angle and light. Left/top = before, right/bottom = after. Label each clearly.

**Layout structure**
```
┌───────────┬───────────┐
│  BEFORE   │   AFTER   │
│   [IMG]   │   [IMG]   │
├───────────┴───────────┤
│ [H]                   │
│ [S] no filter note    │
│ [CTA]          [LOGO] │
└───────────────────────┘
```

**Example copy — "Brightwell Grout Pen":** "Same bathroom, 20 minutes apart." · "No filter. Same lighting. Just Brightwell." · "Try it yourself"

*Compliance: results must be real and typical. For skincare/health, check platform policies on before/after imagery.*

┌───────────────────────┐

│ │      │ Ours │Usual│ │

### P18 · The Carousel Story (5 slides)

| | |
|---|---|
| **Headline** | Slide 1: hook that forces a swipe |
| **Supporting text** | Slides 2–4: story; Slide 5: CTA |
| **CTA** | Slide 5: [CTA] |
| **Ratio** | 4:5 per slide |

**Photo direction:** Consistent style across slides; each slide = one idea. Slide 1 is creator/product photo with bold text.

**Layout structure**
```
[1 HOOK] → [2 PROBLEM] → [3 DISCOVERY] → [4 RESULT] → [5 CTA]
 bold text   photo +       product         result       product +
 + photo     1 line        photo + line    photo + line CTA button
```
Add a small "swipe →" cue on slide 1.

**Example copy — "Brightpath Budget Planner":** 1: "How I found £310 a month I didn't know I had →" · 2: "I thought I was bad with money." · 3: "Turns out I just couldn't see it all in one place." · 4: "Month one: 4 forgotten subscriptions, 1 overpriced phone plan." · 5: "The planner I used → Brightpath. Link in bio."
