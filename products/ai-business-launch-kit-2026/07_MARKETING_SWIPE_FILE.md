## 50 Attention-Grabbing Hook Templates

These are structures for the *opening line* of a post, video, or email — not guarantees that any post will go viral. Use language like "attention-grabbing," never "guaranteed to go viral."

**Question hooks**
1. "Ever wonder why [common problem] keeps happening?"
2. "What if [common belief] was actually wrong?"
3. "Why does nobody talk about [topic]?"
4. "How many of these [number] mistakes are you making?"
5. "What would change if you finally fixed [problem]?"

**Bold statement hooks**
6. "[Common practice] is quietly costing you [resource]."
7. "Most advice about [topic] is outdated."
8. "You don't have a [surface problem] — you have a [real problem]."
9. "This is the least talked-about reason [problem] happens."
10. "[Popular tool/method] isn't the fix everyone thinks it is."

**Story hooks**
11. "Last week, a client told me something that stuck with me."
12. "I almost gave up on this before it worked."
13. "Here's what changed the moment I stopped [old behavior]."
14. "Three months ago, I would have told you this was impossible."
15. "I made this mistake so you don't have to."

**List/number hooks**
16. "5 signs you're dealing with [problem] right now."
17. "3 things I wish someone told me before [milestone]."
18. "7 questions to ask before you [decision]."
19. "4 tools that changed how I [task]."
20. "10 seconds to know if [scenario] applies to you."

**Curiosity hooks**
21. "The real reason [outcome] happens isn't what you think."
22. "Nobody tells you this part of [process]."
23. "Here's the one thing that actually moved the needle."
24. "This small change made a bigger difference than expected."

**Direct-address hooks**
26. "If you're a [audience], read this before you [action]."

28. "Stop doing [common mistake] — here's why."

**Contrarian hooks**

**Result-oriented hooks**

## Lead Magnet Format Templates + AI Prompts

**Checklist**
```
Structure: Title → short intro (1-2 sentences) → grouped, ordered
checkboxes → one closing CTA line.
AI Prompt: "Act as a process consultant. Turn [PROCESS] into a clear,
ordered checklist for [TARGET CUSTOMER], grouped under short headers,
ending with one line pointing them toward [YOUR OFFER]."
```

**Mini-Guide**
```
Structure: Title → problem framing (1 paragraph) → 3-5 short sections
with one actionable tip each → closing CTA.
AI Prompt: "Act as an instructional designer. Write a mini-guide titled
[TITLE] for [TARGET CUSTOMER] covering [3-5 KEY POINTS], each with one
actionable takeaway. End with a soft mention of [YOUR OFFER]."
```

**Template**
```
Structure: Title → instructions for use → the fillable template itself
→ one worked example.
AI Prompt: "Act as a template designer. Build a [TEMPLATE TYPE] template
for [TARGET CUSTOMER] to accomplish [TASK], with clear instructions and
one filled-in example."
```

**Calculator**
```
Structure: Title → what it calculates → inputs needed → simple output
explanation.
AI Prompt: "Act as a product designer. Design a simple calculator that
helps [TARGET CUSTOMER] estimate [WHAT IT CALCULATES], listing the
inputs and calculation logic in plain terms."
```

**Prompt Pack**
```
Structure: Title → how to use these prompts → 8-10 prompts with
name/purpose/prompt text/variables.
AI Prompt: "Act as a prompt engineer. Create 8 AI prompts for [NICHE]
to accomplish [TASK CATEGORY], each with a name, purpose, and
copy-paste prompt text with variables."
```

**Cheat Sheet**
```
Structure: Title → one-page, scannable reference (terms, steps, or
quick answers) → no fluff.
AI Prompt: "Act as a reference-guide writer. Create a one-page cheat
sheet on [TOPIC] for [TARGET CUSTOMER], formatted for fast scanning,
not reading top to bottom."
```

**Resource List**
```
Structure: Title → short intro → categorized list of resources/tools
→ one-line description of each.
AI Prompt: "Act as a resource curator. Create a categorized list of
resources/tools relevant to [TOPIC] for [TARGET CUSTOMER], with a
one-line description of what each is best for."
```

**Quiz**
```
Structure: Title → 5-8 questions → scoring logic → result descriptions
per score band.
AI Prompt: "Act as an assessment designer. Create a [NUMBER]-question
quiz that helps [TARGET CUSTOMER] identify [PROBLEM/TYPE], with
scoring logic and a short description for each result band."
```

**Audit**
```
Structure: Title → what's being audited → self-scoring checklist by
category → interpretation guide.
AI Prompt: "Act as a business auditor. Create a self-audit for [BUSINESS
AREA] that [TARGET CUSTOMER] can score themselves on, with categories,
scoring, and what each score range means."
```

**Workbook**
```
Structure: Title → intro → multiple worksheets (see File 04 for
format) building toward one outcome.
AI Prompt: "Act as an instructional designer. Build a short workbook
(4-6 worksheets) guiding [TARGET CUSTOMER] toward [OUTCOME], following
the structure: prompt/question, space to answer, and a short instruction
line per worksheet."
```

## Outreach System

Ethical outreach only: no spam, no deceptive claims, no pressure tactics, no misrepresenting who you are. Always personalize the bracketed sections with something genuinely specific to the recipient.

### LinkedIn

```
First message:
"Hi [Name], [shared context — mutual connection, their post, their
company]. I help [target customer type] with [problem you solve]. Not
pitching anything here — just wanted to connect since [reason]."

Follow-up #1 (3-5 days later):
"Hi [Name], following up in case this got buried. I recently helped
[similar situation, if true] with [outcome]. Happy to share more if
useful — no pressure either way."

Follow-up #2 (about a week later):
"Hey [Name] — sharing this in case it's relevant: [one piece of genuine
value, e.g., a resource, tip, or observation about their industry].

"Hi [Name], I'll leave this here — if [problem] becomes a priority down
the line, feel free to reach out. Wishing you well either way."

# PART C — AI SALES SYSTEM (Module 8)

## Sales Conversation Framework

```
1. OPEN — build rapport, set the agenda ("Today I'd love to understand
   your situation and see if this is a fit — sound good?")
2. DISCOVER — ask open questions about their problem, goals, and
   current situation
3. REFLECT — summarize what you heard back to them, confirm you
   understood correctly
4. PRESENT — introduce your offer as a direct response to what they
   told you, not a generic pitch
5. ADDRESS — invite and answer questions/objections honestly
6. CLOSE — propose a clear, specific next step
```

## Discovery Call Script

```
OPENING (1-2 min)
"Thanks for making time, [Name]. My plan for today is to understand
what's going on with [problem area], and then I'll share how I might
be able to help — and if it's not a fit, that's a completely fine
outcome too. Sound good?"

DISCOVERY QUESTIONS (10-15 min)
- "Tell me about where things stand right now with [problem area]."
- "What have you already tried?"
- "What's not working about that?"
- "If this were solved, what would be different for you/your business?"
- "What's your timeline for figuring this out?"
- "Is there anyone else involved in this decision?"

TRANSITION
"Based on what you've shared, here's how I typically help people in
your situation..."

PRESENT YOUR OFFER (5 min)
[Use your offer draft from File 02, Module 3]

CLOSE
"Does this feel like a fit based on what we talked about? What
questions do you have?"
[Propose the specific next step — proposal, start date, or a
follow-up call.]
```

## Qualification Questions

```

## Follow-Up System

```

         answer any questions."
Day 7 — "Wanted to check in again — is there anything holding this

          timing changes down the road, I'm happy to revisit."
```

## Objection Handling Framework

```
STEP 1 — Acknowledge: "That's a fair thing to think about."
STEP 2 — Clarify: "Can you tell me more about what's behind that?"
STEP 3 — Respond: Address the specific concern with a direct, honest
         answer (not a scripted deflection).
STEP 4 — Check: "Does that help clarify things, or is there more to
         it?"
```

**Common objections + response starting points:**

| Objection | Response Starting Point |
|-----------|---------------------------|
| "It's too expensive" | Reconnect price to the specific outcome/value they described in discovery |
| "I need to think about it" | "Totally fair — what's the main thing you're weighing?" (surfaces the real objection) |
| "I've tried something like this before and it didn't work" | Ask what specifically didn't work, then explain how your approach differs |
| "I don't have time right now" | Clarify what your process actually requires of their time — it may be less than they assume |
| "I want to compare options first" | Support the comparison honestly — offer what makes your approach specifically different |
