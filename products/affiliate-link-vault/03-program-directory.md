# 03 — PROGRAM DIRECTORY

While the Master Vault tracks individual **links**, the Program Directory tracks each affiliate **program** as a whole — including the account details and status you need but don't want cluttering your link database.

---

## Field Definitions

| Field | What to Enter |
|---|---|
| Program Name | Name of the affiliate program |
| Website | The brand or program's main website |
| Affiliate Network | The network hosting the program, or "Direct" |
| Application Status | Not Applied / Applied / Approved / Rejected / Under Review |
| Approval Date | Date your application was approved |
| Login/Dashboard URL | Where you log in to see stats, get links, and request payout |
| Commission | Summary of the commission structure |
| Cookie Duration | How long referral tracking lasts |
| Payment Threshold | Minimum balance required for payout |
| Payment Method | How this program pays affiliates |
| Contact/Support URL | Affiliate manager email or support page |
| Notes | Requirements, restrictions, renewal dates, anything program-specific |

## Why This Matters

Most affiliate marketers lose track of programs the moment they stop actively promoting them. Over time, dashboard logins get forgotten, application statuses go unchecked, and expired programs keep getting mentioned in old content. The Program Directory exists so that, at any point, you can answer three questions in under a minute:

1. Which programs am I actually part of right now?
2. Where do I log in to check each one?
3. Which are still worth my time, based on commission and fit?

**Tip:** Revisit "Application Status" during your monthly audit (Section 09). Programs under review for more than a few weeks are worth a polite follow-up with the affiliate manager.
