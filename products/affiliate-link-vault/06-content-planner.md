# 06 — AFFILIATE CONTENT PLANNER

Plan affiliate content before you publish it, instead of bolting a link onto whatever you post that day. This planner connects directly to your Master Vault — every piece of content should map back to a specific product.

---

## Field Definitions

| Field | What to Enter |
|---|---|
| Content Title | Working title of the post/video/email |
| Affiliate Product | The product from your Master Vault this content promotes |
| Content Type | See list below |
| Platform | Where it will be published |
| Target Keyword | The primary search term (for SEO-driven content) |
| CTA | Which call-to-action you're using (pull from Section 07) |
| Affiliate Link | The exact link to insert |
| Publication Date | Planned or actual publish date |
| Status | Idea / Drafting / Scheduled / Published / Needs Update |
| Performance Notes | Early signals — engagement, click activity, feedback |

---

## Content Types

| Type | Best For |
|---|---|
| Blog Post | Long-form, SEO-driven affiliate content |
| YouTube Video | In-depth reviews, tutorials, comparisons |
| YouTube Short | Quick tips, hooks, product highlights |
| Instagram Reel | Fast, visual product demos |
| Instagram Post | Static promotion, carousel breakdowns |
| TikTok | Trend-driven, casual recommendations |
| Pinterest | Evergreen, search-driven visual pins |
| Email | Direct promotion to your list |
| Newsletter | Roundups, curated recommendations |
| Comparison Article | "X vs. Y" style content |
| Tutorial | Step-by-step how-to using the product |
| Product Review | In-depth single-product breakdown |
| Resource Page | A running list/page of recommended tools |

## Planning Tips

- **Start from the product, not the content idea.** Ask "what content would genuinely help someone decide on this product?" rather than forcing a link into unrelated content.
- **Batch by category.** Plan several pieces around one Link Organizer category (Section 04) at a time — it's faster to research and write when you're staying in one topic lane.
- **Update Status honestly.** A planner full of "Idea" rows that never move to "Published" tells you where your bottleneck actually is.
- **Cross-reference with the Link Audit Checklist (Section 09).** Any published content over 90 days old should get a link-health check.
