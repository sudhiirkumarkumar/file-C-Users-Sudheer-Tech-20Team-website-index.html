# 02 — AFFILIATE LINK MASTER VAULT

This is the central database of your entire affiliate business — every link, every program, every key detail in one place. Build it as one tab/table in Sheets, Excel, or Notion, with one row per affiliate link.

---

## Field Definitions

| Field | What to Enter |
|---|---|
| Affiliate Program | The name of the program you joined (e.g., the brand's own affiliate program name) |
| Brand/Merchant | The company or creator behind the product |
| Product Name | The specific product or service being promoted |
| Product Category | Use categories from the Link Organizer (Section 04) |
| Affiliate Network | The network the program runs through, if any (e.g., a third-party affiliate platform), or "Direct" if it's an in-house program |
| Affiliate URL | Your full tracking link |
| Deep Link | A link to a specific page/product (not just the homepage), if supported |
| Affiliate ID | Your unique affiliate/referral ID or username |
| Commission Rate | The percentage or flat amount you earn |
| Commission Type | One-time, Recurring, Tiered, or Flat Fee |
| Cookie Duration | How long the tracking cookie lasts (e.g., 30 days) |
| Payout Threshold | Minimum balance required before you get paid |
| Payment Method | How you're paid (e.g., bank transfer, PayPal, check) |
| Promotional Channel | Where you use this link (Blog, YouTube, Instagram, Email, etc.) |
| Target Audience | Who this product is relevant to |
| Product Price | The retail price of the product/service |
| Status | Active / Check Required / Broken / Expired / Pending / Rejected / Replaced (see Section 04) |
| Date Added | When you added this link to your vault |
| Last Checked | The last date you verified this link works |
| Notes | Anything else worth remembering (restrictions, promo codes, special terms) |

## Setup Tips

- **One row per link, not per program.** If a single program has multiple products you promote separately, give each its own row so performance and status can be tracked individually.
- **Use dropdown/data-validation lists** for Product Category and Status if building this in Sheets, Excel, or Notion — it keeps entries consistent and makes filtering reliable.
- **Never guess commission or cookie data.** Copy it directly from the program's official terms or affiliate dashboard, and re-check it during your monthly audit since programs can change terms without much notice.
