# 13 — PRODUCT RECOMMENDATION DATABASE

A holding area for products you're **considering** promoting but haven't fully committed to yet. Once a product clears your Evaluation Scorecard (Section 12) and you've joined the program, move it into your Master Vault (Section 02) as an active link.

Think of this as your research pipeline — the space between "I noticed this product" and "I'm actively promoting this product."

---

## Field Definitions

| Field | What to Enter |
|---|---|
| Product | Name of the product/service |
| Brand | Company behind it |
| Category | Use Link Organizer categories (Section 04) |
| URL | The product's main website (not an affiliate link yet) |
| Affiliate Program | Which network or program it runs through, if known |
| Commission | Commission info, once you've confirmed it |
| Cookie Duration | Cookie length, once confirmed |
| Audience | Who this would be relevant for |
| Problem Solved | What need or pain point this product addresses |
| Content Ideas | Rough ideas for how you'd promote it |
| CTA | Which CTA style would fit (reference Section 07) |
| Status | Researching / Applying / Applied / Approved / Not Pursuing |
| Notes | Anything else worth remembering |

## How This Database Fits the Workflow

```
Product Recommendation Database  →  Product Evaluation Scorecard  →  Program Directory  →  Master Vault
   (spot & research it)              (score it honestly)              (apply & track account)   (go live & promote)
```

**Tips for building this pipeline:**
- Add a product here the moment you notice it — from your own use, audience questions, competitor research, or industry newsletters. Don't wait until you're "sure" about it.
- Revisit this database monthly alongside your Link Audit (Section 09) — move ready products forward, and clean out ones you've decided not to pursue.
- Use the "Not Pursuing" status instead of deleting rows — it's useful to remember what you already evaluated and passed on, and why.
