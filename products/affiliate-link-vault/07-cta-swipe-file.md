# 07 — CTA SWIPE FILE
## 30 Reusable Affiliate Call-to-Action Templates

Use these as starting points, not word-for-word scripts. Swap in your product name, benefit, and tone. Every CTA below is written to be honest and non-hypey — no urgency gimmicks, no income promises, no "guaranteed results" language.

Placeholders use brackets like [Product] — replace with your specific details before publishing.

## Usage Notes

- **Match the CTA to the content type** — a resource-page CTA reads differently than a comparison-article CTA. Cross-reference with the Content Planner (Section 06).
- **Always pair a CTA with a disclosure** where required by the platform (Section 08).
- **Avoid manufactured urgency** ("Only 3 spots left!", "Price goes up tonight!") unless it is a real, verifiable fact about the offer — false urgency damages trust and can violate platform and network policies.
