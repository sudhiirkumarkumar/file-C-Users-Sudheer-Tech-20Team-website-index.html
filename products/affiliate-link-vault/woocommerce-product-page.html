Frequently Asked Questions

Is this a real software or a template?

It's a template system (spreadsheet/Notion/printable format) — no software installation or subscription required.

Do I need technical skills to use it?

No. If you can use a spreadsheet or Notion page, you can use this system.

Does this include real affiliate links already set up?

No — this is an organizational system. You add your own real affiliate programs and links; none are pre-included.

What format do I receive it in?

Content is provided ready to import into Google Sheets, Excel, or Notion, and to convert into a printable workbook.

Is this suitable for complete beginners?

Yes — the included Quick Start Guide walks you through setup in about 30 minutes.

Does it track clicks and sales automatically?

No — performance data is entered manually from your own affiliate dashboards using the built-in tracker and formulas.
