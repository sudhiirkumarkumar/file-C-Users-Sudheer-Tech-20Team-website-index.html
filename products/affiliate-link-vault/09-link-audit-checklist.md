# 09 — AFFILIATE LINK AUDIT CHECKLIST
## Monthly Audit

This is the single habit that keeps the entire vault trustworthy. Run through this checklist once a month, per active piece of content (prioritize your highest-traffic content first if you have a large backlog).

---

## Monthly Audit Checklist

```
[ ] Link still works
[ ] Affiliate tracking works
[ ] Correct product
[ ] Correct landing page
[ ] Affiliate ID is correct
[ ] Product is still available
[ ] Commission information checked
[ ] Disclosure is present
[ ] CTA is relevant
[ ] Content is up to date
[ ] Promotional channel is appropriate
[ ] Broken links replaced
[ ] Expired programs removed
```

---

## What Each Item Means

| Checklist Item | How to Verify |
|---|---|
| Link still works | Click it — does it load without errors? |
| Affiliate tracking works | Confirm your affiliate ID/parameter appears in the URL after any redirect |
| Correct product | Does it land on the product you intended, not a discontinued or renamed one? |
| Correct landing page | Is it the specific page you meant (deep link), not just a generic homepage? |
| Affiliate ID is correct | Double-check against your Master Vault entry — copy-paste errors happen |
| Product is still available | Confirm the product/service hasn't been discontinued |
| Commission information checked | Re-confirm rate, cookie duration, and terms against the program's current page |
| Disclosure is present | Is the disclosure visible and still accurate for this content? |
| CTA is relevant | Does the CTA still match the product and context? |
| Content is up to date | Are prices, features, or claims in the content still accurate? |
| Promotional channel is appropriate | Is this still the right channel, or has performance shifted elsewhere? |
| Broken links replaced | Any BROKEN-status link from last month — has it been fixed or swapped? |
| Expired programs removed | Any EXPIRED program — has it been fully removed from live content? |

---

## Suggested Monthly Workflow

1. **Filter your Master Vault** (Section 02) by Status = "CHECK REQUIRED" or older than 30 days since Last Checked.
2. **Work through the checklist** above for each link.
3. **Update Status and Last Checked** in the Master Vault for every link reviewed.
4. **Log any changes** in the Notes field (e.g., "commission rate changed from X to Y on [date]").
5. **Update your Affiliate Dashboard** (Section 10) with the latest totals once the audit is complete.

**Tip:** Block a recurring 20–30 minute slot on the same day each month. A vault that's audited consistently stays reliable; one that's audited "whenever I remember" tends to accumulate broken links and outdated information.
