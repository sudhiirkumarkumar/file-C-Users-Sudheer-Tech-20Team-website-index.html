# Section 10: Product Packaging Checklist

How you package the final files affects customer trust as much as the content itself. Use this checklist and folder structure before you upload your product anywhere.

---

## Files to Consider

- [ ] **Main PDF** — the core rebranded product
- [ ] **Workbook** — if separated from the main guide
- [ ] **Checklist(s)** — standalone quick-reference files
- [ ] **Bonus files** — from Section 9
- [ ] **Editable Canva templates** — link or file, if you're offering editable versions
- [ ] **License document** — your own terms for what your customers can do with what they bought from you (separate from the PLR license you operated under — see Section 11)
- [ ] **Read Me file** — plain-language instructions on what's inside and how to use it
- [ ] **Product preview images** — listing thumbnail, mockup, and any interior page previews used in marketing

---

## Recommended Folder Structure

```
PLR-Rebrand-Kit/
│
├── Start-Here/
│   └── Read-Me.pdf
│
├── Main-Guide/
│   └── [Product-Name]-Main-Guide.pdf
│
├── Worksheets/
│   └── [Product-Name]-Workbook.pdf
│
├── Prompt-Vault/
│   └── (if applicable to your product)
│
├── Bonuses/
│   ├── Bonus-1-[Name].pdf
│   └── Bonus-2-[Name].pdf
│
├── Canva-Templates/
│   └── Editable-Template-Link.pdf (or .txt with the link)
│
├── License/
│   └── Your-Product-License.pdf
│
└── Marketing-Assets/
    ├── Cover-Thumbnail.png
    └── Preview-Images/
```

---

## Read Me File — What to Include

- [ ] A one-paragraph welcome and thank-you
- [ ] A list of exactly what's inside the folder (matching the structure above)
- [ ] Suggested order to go through the files
- [ ] How to access editable Canva templates (if included)
- [ ] Your support contact ([YOUR WEBSITE] / [YOUR BRAND NAME] contact page or email)
- [ ] A short note on your product's own usage terms (see Section 11)

---

## File Naming Conventions

Keep file names clean, consistent, and descriptive — avoid spaces where possible and avoid version-number chaos (e.g., `finalv3_EDIT_USE THIS ONE.pdf`).

**Good example:**
```
desk-to-strong-30-day-plan-main-guide.pdf
desk-to-strong-30-day-plan-workbook.pdf
desk-to-strong-30-day-plan-bonus-habit-tracker.pdf
```

---

## Final Packaging Checklist

- [ ] All files use consistent naming
- [ ] All files use consistent branding (fonts, colors, logo/name placement)
- [ ] Folder structure matches the recommended layout above
- [ ] No stray draft files, unused images, or leftover PLR source files included
- [ ] Total download size is reasonable (compress large image-heavy PDFs if needed)
- [ ] Read Me file is included and accurate
- [ ] License document is included and matches what you're actually permitted to offer (see Section 11)
- [ ] Preview/marketing images are separated from the customer-facing files
