# Section 8: Canva Design Checklist

A page-by-page checklist for building your final product in Canva, including recommended dimensions and export settings.

---

## Recommended Page Dimensions

| Product Type | Recommended Size |
|---|---|
| Digital ebook / workbook (screen-first) | 8.5" x 11" (Letter) at 300 DPI, or Canva's "A4 Document" |
| Printable worksheets | 8.5" x 11" (US Letter) — the most universally printable size |
| Product cover (listing thumbnail) | 1:1 square (e.g., 2000 x 2000px) for Etsy/Gumroad listings |
| 3D-style mockup cover | Design flat first, then apply a mockup template at 2000px+ on the longest side |
| Social media promo graphics | 1080 x 1080px (square) or 1080 x 1350px (portrait) |

**Beginner tip:** design at 300 DPI whenever the product may be printed, and always design in RGB color mode for anything that will be sold and delivered as a digital file (only switch to CMYK if you are sending files to a physical printer).

---

## Page-by-Page Checklist

### Cover
- [ ] Title is the largest, most dominant element
- [ ] Subtitle is visible but secondary
- [ ] Brand name/author name is present but small
- [ ] Uses your chosen visual style direction (Section 7)
- [ ] No leftover PLR provider branding or watermarks
- [ ] Exported separately as a listing thumbnail (square) in addition to the interior page version

### Table of Contents
- [ ] Lists every major section with matching page numbers
- [ ] Uses consistent heading style matching the rest of the document
- [ ] Updated last, after final page count is confirmed

### Section Divider
- [ ] One consistent divider template reused for every new section
- [ ] Section number and title clearly visible
- [ ] Matches brand colors and fonts

### Text Pages
- [ ] Consistent margins on every page
- [ ] Body text is legible (11–12pt minimum for print)
- [ ] Headings follow a consistent size/weight hierarchy
- [ ] Paragraphs are broken up — no dense walls of text

### Checklist Pages
- [ ] Checkbox icons are consistent in style throughout
- [ ] Items are short and scannable
- [ ] Grouped under clear subheadings if the list is long

### Worksheet Pages
- [ ] Clear instructions at the top of each worksheet
- [ ] Enough blank space for handwriting or digital typing
- [ ] Fields/lines aligned consistently
- [ ] Page works both printed and filled in digitally (if using Canva's fillable text fields)

### Quote Pages
- [ ] Pulled quote or key takeaway is large and easy to read at a glance
- [ ] Used sparingly — only for genuinely important statements
- [ ] Matches brand color palette, not a random accent

### CTA Page
- [ ] Clear single call-to-action (not multiple competing asks)
- [ ] Button or box visually distinct using secondary brand color
- [ ] States exactly what the reader should do next

### About-the-Author Page
- [ ] Uses your placeholder or real brand identity: [YOUR NAME], [YOUR BRAND NAME], [YOUR WEBSITE]
- [ ] Short, friendly bio (3–5 sentences)
- [ ] Optional headshot or logo, sized consistently with the rest of the design

### Bonus Page
- [ ] Clearly labeled as a bonus (not confused with the main content)
- [ ] Lists what the bonus is and how to use it
- [ ] Matches the overall design system

### Thank-You Page
- [ ] Thanks the customer by name/placeholder
- [ ] Reminds them where to find support or contact info
- [ ] Optional: invites them to leave a review or follow your brand

## Export Settings

| Purpose | Recommended Export |
|---|---|
| Main delivered PDF | PDF Print (highest quality), flattened, with all fonts embedded |
| Web/preview version | PDF Standard (smaller file size) if the print version is too large to deliver easily |
| Listing thumbnail | PNG or JPG, 2000 x 2000px, sRGB color |
| Social promo graphics | PNG for graphics with transparency, JPG for photo-heavy posts |

**Before exporting, always:**
- [ ] Spell-check every page
- [ ] Confirm all page numbers are correct and in order
- [ ] Confirm all links (if any) are clickable and correct
- [ ] Preview the PDF at 100% zoom to check for layout issues
- [ ] Confirm file size is reasonable for easy download (compress images if the file is too large)
