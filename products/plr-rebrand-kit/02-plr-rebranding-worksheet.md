Print this worksheet or copy it into a document before you start rewriting anything. Fill it in completely for every PLR product you rebrand — it becomes your reference sheet for every later step (naming, design, and marketing all pull from what you write here).

## Part C — Positioning Prompts

Answer each prompt in 1–3 sentences. These answers will feed directly into your product description (Section 13) and sales page (Section 14), so write them as real sentences, not fragments.

**1. What problem does this product solve?**
_______________________________________________

**2. Who needs this solution most?**
_______________________________________________

**3. What makes my version different from the original PLR (and from other sellers using the same PLR)?**
_______________________________________________

**4. What can I add that improves the original?**
_______________________________________________

**5. What specific outcome should the customer expect after using this product?**
_______________________________________________

## Worked Example (Fitness Niche)

To show how this looks filled in, here's a sample using a generic "30-Day Fitness Challenge" PLR pack repositioned for a specific audience:

| Field | Answer |
|-------|--------|
| Original PLR title | "30-Day Fitness Challenge" |
| Original target audience | General fitness beginners |
| New product name | "The Desk-to-Strong 30-Day Movement Plan" |
| New target customer | Remote workers with limited time and no gym access |
| New promise | Build a consistent movement habit in 30 days using nothing but a chair, a wall, and 15 minutes a day |
| What makes my version different | Every workout is designed for a home office — no equipment, no gym, includes a printable desk-break tracker |
| What I added | A "5-Minute Reset" bonus routine for mid-workday breaks, plus a printable habit tracker |

Use this same structure for any niche — small business, personal development, marketing, productivity, career, social media, finance education, coaching, or freelancing.

## Quick-Fill Version (for repeat use)

Once you've rebranded a few products, use this shortened version to move faster:

```
ORIGINAL: [title] → NEW: [title]
AUDIENCE SHIFT: [old audience] → [new audience]
PROMISE: [one sentence outcome]
DIFFERENTIATOR: [what makes this version different]
ADDED VALUE: [what you're adding that the original didn't have]
```
