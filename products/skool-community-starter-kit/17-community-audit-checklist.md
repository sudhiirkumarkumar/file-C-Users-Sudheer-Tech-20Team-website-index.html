# COMMUNITY AUDIT CHECKLIST
## Monthly Review
### [CHECKLIST]

Run through this once a month to keep your community healthy, current, and growing intentionally rather than by accident.

---

## Community
```
[ ] Positioning statement still accurately reflects the community
[ ] Community name/branding still feels right
[ ] Description is up to date
Notes: _________________________________________________________
```

## Content
```
[ ] Reviewed which post types got the most engagement this month
[ ] Content calendar planned for next month
[ ] Outdated or irrelevant pinned posts updated/removed
Notes: _________________________________________________________
```

## Engagement
```
[ ] Engagement Rate calculated (see KPI Tracker, 16)
[ ] Identified most active members this month
[ ] Identified any drop-off in participation and possible causes
Notes: _________________________________________________________
```

## Members
```
[ ] New member count reviewed
[ ] Inactive members identified (consider a re-engagement post)
[ ] Any member issues/conflicts reviewed and resolved
Notes: _________________________________________________________
```

## Onboarding
```
[ ] Onboarding sequence tested from a new member's perspective
[ ] Welcome Post and "Start Here" post still accurate
[ ] New members from this month successfully completed onboarding steps
Notes: _________________________________________________________
```

## Classroom
```
[ ] Classroom content still accurate and relevant
[ ] Any new lessons/resources needed based on member questions this month
[ ] Module completion patterns reviewed (where are members getting stuck?)
Notes: _________________________________________________________
```

## Growth
```
[ ] Reviewed which growth channel brought the most members this month
[ ] Growth Plan (15) updated based on what worked
[ ] Any new partnership or promotion opportunities identified
Notes: _________________________________________________________
```

## Monetization (if applicable)
```
[ ] Revenue/conversion numbers reviewed
[ ] Any member feedback on paid offers considered
[ ] Monetization Planner (13) revisited if approach needs adjusting
Notes: _________________________________________________________
```

---

## After the Audit

1. Update your KPI Tracker (16) with this month's numbers.
2. Adjust your next 30-Day Content Calendar (09) and Growth Plan (15) based on what you found.
3. Address anything flagged in the Notes sections above before the next audit cycle.
