# CLASSROOM PLANNER

A beginner-friendly structure for your Skool classroom (or any course/curriculum area attached to your community). Six modules, each with a clear purpose so members always know why they're there and what "done" looks like.

---

## [EXAMPLE] Classroom Structure

### MODULE 1 — START HERE
| Field | Details |
|---|---|
| Purpose | Orient new members so they know how the community and classroom work |
| Suggested Lessons | "Welcome & How This Works," "How to Get the Most From This Community," "Meet Your Host" |
| Suggested Resources | Community map/index, FAQ, how-to-navigate guide |
| Completion Goal | Member understands the community structure and knows their first action step |

### MODULE 2 — FOUNDATIONS
| Field | Details |
|---|---|
| Purpose | Teach the core concepts every member needs before moving to implementation |
| Suggested Lessons | 3-5 lessons covering the fundamental knowledge/skill for your niche |
| Suggested Resources | Glossary of key terms, a foundational framework or model, a "start here" checklist |
| Completion Goal | Member can explain the core concept in their own words |

### MODULE 3 — IMPLEMENTATION
| Field | Details |
|---|---|
| Purpose | Move members from knowing to doing |
| Suggested Lessons | Step-by-step walkthroughs, templates in action, worked examples |
| Suggested Resources | Templates, worksheets, checklists referenced in the lessons |
| Completion Goal | Member has taken at least one real action / produced one real output |

### MODULE 4 — ADVANCED STRATEGIES
| Field | Details |
|---|---|
| Purpose | Deepen skills for members who've completed the basics |
| Suggested Lessons | Edge cases, optimization, troubleshooting common problems |
| Suggested Resources | Case studies, advanced templates, optional deep-dives |
| Completion Goal | Member can handle more complex or less common situations independently |

### MODULE 5 — RESOURCES
| Field | Details |
|---|---|
| Purpose | A living reference library members return to |
| Suggested Lessons | Not lesson-based — organized as a resource index instead |
| Suggested Resources | Templates, swipe files, tool recommendations, cheat sheets |
| Completion Goal | N/A — this module is for reference, not linear completion |

### MODULE 6 — BONUSES
| Field | Details |
|---|---|
| Purpose | Extra value that rewards active/engaged members |
| Suggested Lessons | Guest content, bonus trainings, exclusive templates |
| Suggested Resources | Anything time-limited or contributed by guest experts |
| Completion Goal | N/A — optional, exploratory content |

## Setup Tips

- **Start with Modules 1-3 only.** You don't need Modules 4-6 fully built to launch — add them as your community grows and you learn what members actually need.
- **Keep individual lessons short.** A 5-10 minute lesson gets finished; a 45-minute one often doesn't.
- **Link classroom lessons to community posts.** Reference relevant lessons in your discussion posts (Section 10) so the classroom and community feed reinforce each other.
