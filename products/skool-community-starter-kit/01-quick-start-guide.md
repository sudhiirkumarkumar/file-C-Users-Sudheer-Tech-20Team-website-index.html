# QUICK-START IMPLEMENTATION PLAN
## LAUNCH YOUR COMMUNITY IN 48 HOURS
### [TEMPLATE]

If you want to move fast, this is the compressed version of the full 7-Day Launch Plan (14-launch-plan.md). It assumes you can dedicate focused blocks of time across two days. If you'd rather spread this out, use the 7-Day plan instead.

---

## DAY 1 — DEFINE, STRUCTURE, SET UP, PREPARE CONTENT

### Block 1: Define (60-90 min)
```
[ ] Complete the Community Idea Worksheet (03-Community-Positioning-Workbook)
[ ] Write your Positioning Statement using one of the 10 formulas
[ ] Write your Community Description
```

### Block 2: Structure (45-60 min)
```
[ ] Choose your category structure (04-Community-Structure-Blueprint)
[ ] Set up your Skool categories to match
[ ] Set up your classroom's first 3 modules (05-Classroom-Planner)
```

### Block 3: Set Up (45-60 min)
```
[ ] Publish your Community Rules (06-Community-Rules-Template)
[ ] Create and pin your "Start Here" post (07-Onboarding-Swipe-File)
[ ] Add branding — banner, logo, colors
```

### Block 4: Prepare Content (60-90 min)
```
[ ] Draft your Welcome Post
[ ] Draft your first 5 posts using the Post Swipe File (10) and Day 1-5 of the 14-Day Engagement Plan (08)
[ ] Choose your first challenge from the Challenge Kit (11)
```

**End of Day 1 checkpoint:** Your community exists, is structured, has rules and a classroom foundation, and you have content ready to publish.

---

## DAY 2 — FINALIZE, PUBLISH, INVITE, WELCOME MEMBERS, START ENGAGEMENT

### Block 1: Finalize (30-45 min)
```
[ ] Review everything as if you were a brand-new member seeing it for the first time
[ ] Fix any confusing wording, broken structure, or missing pieces
[ ] Confirm your Welcome Post and Rules are pinned correctly
```

### Block 2: Publish (30 min)
```
[ ] Publish your Welcome Post
[ ] Publish your first 1-2 pieces of content
[ ] Announce your first challenge
```

### Block 3: Invite (30-60 min)
```
[ ] Build your invitation list (personal network, email list, social followers)
[ ] Send personal invitations — not just a mass announcement
[ ] Post your community launch on any relevant social channels
```

### Block 4: Welcome Members (ongoing throughout the day)
```
[ ] Personally welcome each new member as they join (Onboarding Swipe File, template #8)
[ ] Reply to every introduction post
```

### Block 5: Start Engagement (ongoing)
```
[ ] Post Day 1 of the 14-Day Engagement Plan (08)
[ ] Reply to every comment
[ ] Encourage your first few members to introduce themselves
```

**End of Day 2 checkpoint:** Your community is live, members have been personally invited and welcomed, and your first engagement rhythm has started.
