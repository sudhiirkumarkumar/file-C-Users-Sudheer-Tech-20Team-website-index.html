## Content Type Rotation Guide

| Content Type | Purpose | Suggested Frequency |
|---|---|---|
| Educational | Build authority, teach something | 2-3x/week |
| Engagement | Low-effort interaction | 2-3x/week |
| Questions | Learn about your audience, spark discussion | 1-2x/week |
| Polls | Fast, easy participation | 1x/week |
| Challenges | Structured activity, accountability | Ongoing per Challenge Kit (11) |
| Member Wins | Recognition, social proof | 1-2x/week |
| Resources | Deliver tangible value | 1x/week |
| Behind-the-Scenes | Build connection/trust | 1x/week |
| Case Studies | Show real application | 1x every 1-2 weeks |
| Community Discussions | Deepen conversation | 1x/week |
| Quick Tips | Fast, save-worthy value | 1-2x/week |
| Weekly Reviews | Create rhythm, close the loop | 1x/week |

## Reusing This Calendar

This 30-day structure is designed to repeat. Once you complete Day 30, start again from a Day-15-style rotation with fresh topics — the content **types** stay the same, but swap in new specifics each month based on what resonated (check your KPI Tracker, Section 16, for which post types got the most engagement).
