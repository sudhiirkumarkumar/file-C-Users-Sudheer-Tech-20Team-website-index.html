# SKOOL COMMUNITY SETUP CHECKLIST
## [CHECKLIST]

A step-by-step launch checklist covering everything from initial planning through your first invitations. Work through it in order — each stage builds on the one before it.

---

## Stage 1: Before Setup

```
[ ] Define your niche (use 03-Community-Positioning-Workbook)
[ ] Define your target audience / ideal member
[ ] Define your community promise (the transformation you offer)
[ ] Select your community name
[ ] Prepare branding — logo, banner image, color palette
[ ] Draft your welcome message
```

## Stage 2: Community Setup

```
[ ] Write your community description (use the template in 03)
[ ] Create your category structure (use 04-Community-Structure-Blueprint)
[ ] Add starting resources (guides, links, files members will need)
[ ] Build your classroom structure (use 05-Classroom-Planner)
[ ] Publish your community rules (use 06-Community-Rules-Template)
[ ] Create and pin your welcome post
[ ] Set up your member onboarding sequence (use 07-Onboarding-Swipe-File)
```

## Stage 3: Launch Preparation

```
[ ] Draft your first 5-10 posts in advance
[ ] Plan your first engagement activities (polls, questions, intros)
[ ] Prepare your first challenge (use 11-Challenge-Kit)
[ ] Build a content calendar for your first 30 days (use 09)
[ ] Prepare your member invitation list and message
[ ] Confirm everything looks correct from a brand-new member's point of view
```

---

## How to Use This Checklist

1. Print it or duplicate it into your own task tool.
2. Work top to bottom — Stage 1 decisions shape everything in Stage 2 and 3.
3. Don't skip Stage 1 to "save time." A community built without clear positioning is the single most common reason beginners stall out in the first 30 days (see 18-Common-Beginner-Mistakes).
4. Once every box is checked, you're ready for either the 48-Hour Quick Start (01) or the full 7-Day Launch Plan (14).
