17. Common Issues & Troubleshooting

Issue: Download Links Not Working

Cause: File path incorrect or file permissions wrong

Solution:

  1. Check file is uploaded to /wp-content/uploads/woocommerce_uploads/
  2. Verify file permissions are 644
  3. Try re-uploading the file
  4. Check file size doesn't exceed hosting limit

Issue: Email Not Sending to Customers

Cause: SMTP configuration or email limits

Solution:

  1. Install WP Mail SMTP plugin
  2. Connect Gmail or SendGrid account
  3. Send test email from WooCommerce
  4. Check spam folder on test account
  5. Whitelist your domain in email service

Issue: Product Not Showing in Shop

Cause: Product not published or visibility settings

Solution:

  1. Check product status is "Publish"
  2. Verify product category is assigned
  3. Check product visibility = "Visible"
  4. Confirm product isn't out of stock (if configured)
  5. Clear WordPress cache if using caching plugin

Issue: Low Conversion Rate (<1%)

Cause: Product page issues, pricing, or traffic quality

Solution:

  1. Improve product images (biggest conversion factor)
  2. Add customer testimonials/reviews
  3. Add FAQ section to address objections
  4. Test different headlines and copy
  5. Analyze visitor behavior (heatmaps with Hotjar)
  6. Check Google Analytics for bounce points
