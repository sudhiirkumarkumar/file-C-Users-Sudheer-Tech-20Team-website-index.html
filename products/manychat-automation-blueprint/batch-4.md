# SECTION 10 — FOLLOW-UP AUTOMATIONS

Follow-ups should feel helpful, not spammy. The rule of thumb: **each follow-up should add something new** — a helpful nudge, a new angle, or an easy out — never just "still there?"

| # | SITUATION | TIMING | TRIGGER | MESSAGE | CTA |
|---|---|---|---|---|---|
| 1 | **No Response** | 24 hrs after last message | No reply to previous DM | Hey [NAME], just floating this back up in case it got buried — still happy to help with [Topic]! | "Yes, Still Interested" / "No Thanks" |
| 2 | **Downloaded Freebie** | 24–48 hrs after delivery | Resource link opened/delivered | Hey [NAME], did [FREE RESOURCE] help with what you were looking for? | "It Helped!" / "I Have a Question" |
| 3 | **Asked About Product** | 2 days after product info sent | Product enquiry flow completed, no purchase | Hi [NAME], any questions about [PRODUCT NAME] I can help clear up? | "Yes, I Have One" / "Ready to Buy" |
| 4 | **Asked About Price** | 24 hrs after price sent | Price shared, no reply | Hi [NAME], just checking in on the pricing for [PRODUCT NAME] — happy to break it down further. | "Explain More" / "I'll Take It" |
| 5 | **Clicked But Didn't Purchase** | 24 hrs after link click | Link click tracked, no purchase confirmation | Hey [NAME], noticed you checked out [PRODUCT NAME] — any questions holding you back? | "Ask a Question" / "Get [DISCOUNT CODE]" |
| 6 | **Requested Consultation** | 24 hrs after booking link sent | Booking flow started, not completed | Hi [NAME], still want to grab a time for your consultation? Here's the link again: [BOOKING LINK] | "Book Now" |
| 7 | **Started Conversation** | 1 hr after first message with no second reply | First DM sent, no button tap | Hey [NAME], just want to make sure this came through okay — happy to help with anything! | "Continue" |
| 8 | **Abandoned Conversation** | 3 days after conversation stalls | No activity for 72 hours | Hi [NAME], hope things have been busy! Wanted to check if you still have questions about [Topic] or if now isn't the right time. | "Still Interested" / "Not Right Now" |
| 9 | **Interested Lead** | 3–5 days after showing interest | Positive reply/tag applied, no conversion | Hey [NAME], following up on [Topic] — I think [PRODUCT NAME/SERVICE] could really help with [Their Goal]. Want the details again? | "Yes, Send Details" |
| 10 | **Existing Customer** | 7–14 days after purchase | Purchase tag applied | Hi [NAME], hope you're loving [PRODUCT NAME] so far! Let me know if you need anything, or if you'd like to hear about [Related Product/Upgrade]. | "I Need Help" / "Tell Me More" |

> **Pro Tip:** Set a hard limit of 3 follow-ups per unresponsive lead. After that, send one final "no-pressure" message (Section 12 has a ready-made one) and let the automation stop — more than that reads as spam and risks Instagram/Facebook restricting your account.

> **Beginner Mistake:** Sending follow-ups at odd hours (e.g., 3 AM) because "24 hours later" landed there. Check the current ManyChat interface/options for delay/scheduling settings that let you restrict delivery to reasonable hours.

# SECTION 11 — KEYWORD AUTOMATION LIBRARY

Keywords are the single word or phrase someone types to trigger a flow. Use this library to plan yours.

| KEYWORD | INTENDED PURPOSE | TRIGGER IDEA | RECOMMENDED RESPONSE |
|---|---|---|---|
| **GUIDE** | Deliver a free guide | Comment on a guide-promo post | Send guide link + ask permission for more tips |
| **FREE** | General lead magnet delivery | Comment on any freebie post | Send resource + capture email |
| **INFO** | Share product details | Comment/DM asking about a product | Send overview + product link |
| **PRICE** | Answer pricing questions | DM/comment containing "price" or "cost" | Send price + what's included |
| **LINK** | Send a direct product/sales link | Comment asking "where do I buy" | Send purchase link directly |
| **BUY** | Route to purchase | Comment/DM showing buying intent | Send checkout link + support offer |
| **DISCOUNT** | Deliver a promo code | Comment on a sale/promo post | Send code + expiry reminder |
| **COURSE** | Share course curriculum | Comment on course-related content | Send curriculum + enrollment link |
| **HELP** | Route to support or FAQ | DM containing "help" | Trigger FAQ menu |
| **BOOK** | Start booking flow | Comment/DM about appointments | Send booking link |
| **DEMO** | Share a product demo | Comment asking to see the product in action | Send demo video/link |
| **START** | Kick off onboarding or welcome | First DM ever, or "get started" button | Trigger main welcome flow |
| **CHECKLIST** | Deliver a checklist freebie | Comment on checklist-promo post | Send checklist + email capture |
| **TEMPLATE** | Deliver a template freebie | Comment on template-promo post | Send template + related offer |
| **OFFER** | Share a special offer | Comment/DM asking about deals | Send current offer + CTA |
| **MORE** | Continue an earlier conversation | Reply to a previous automated message | Resume flow at last step |
| **DETAILS** | Provide fuller product/service info | Comment/DM asking "tell me more" | Send detailed breakdown |
| **JOIN** | Start a signup/membership flow | Comment on a community/membership post | Send join link + welcome |
| **WEBINAR** | Register for a webinar | Comment on webinar-promo post | Send registration link |
| **CONSULT** / **CONSULTATION** | Start consultation booking | Comment/DM requesting a call | Send qualifying question + booking link |
| **SHOP** | Send storefront/catalog link | Comment/DM on e-commerce post | Send shop link |
| **SUPPORT** | Route to customer service | DM containing "support" or "issue" | Trigger support menu |
| **REFUND** | Handle refund questions | DM containing "refund" | Send refund policy + support email |
| **YES** | Confirm interest / move flow forward | Button tap or typed "yes" | Continue to next flow step |
| **NO** | Decline / exit flow gracefully | Button tap or typed "no" | Send polite close-out message |
| **STOP** | Opt out of messages | DM containing "stop" or "unsubscribe" | Confirm opt-out (required for compliance) |
| **PRICING** | Same as PRICE, alternate phrasing | DM/comment containing "pricing" | Send price info |
| **CONTACT** | Provide direct contact info | DM asking "how do I reach you" | Send [SUPPORT EMAIL] + DM option |
| **SAMPLE** | Share a sample/preview | Comment/DM asking to see a sample | Send sample link |
| **NEWSLETTER** | Sign up for email list | Comment/DM about updates | Capture email for list |
| **REVIEW** | Request or share testimonials | Comment/DM about social proof | Send testimonials or ask for a review |
| **APPLY** | Start an application flow | Comment on a hiring/program post | Send application form/link |

> **Quick Tip:** Keep keywords to a single, obvious word wherever possible. ManyChat can match "contains" a keyword, so "GUIDE" will trigger on comments like "send me the GUIDE please!" — check the current ManyChat interface/options for exact match vs. "contains" settings.

> Hi [NAME], noticed our chat got cut off — happy to pick back up whenever works for you.

> You're in, [NAME]! 🎉 Your order for [PRODUCT NAME] is confirmed — check [EMAIL] for full access details.

> Since you're already using [PRODUCT NAME], you might also love [Related Product] — want a quick look?
